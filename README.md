# API de gestion d'incidents

Ce projet est une API REST développée avec Python et FastAPI pour centraliser le suivi des incidents techniques d'une organisation. Elle permet de consulter, rechercher et administrer des incidents selon leur service, leur priorité et leur état, avec des données d'exemple générées de façon reproductible.

L'objectif est de construire progressivement une API professionnelle : persistance avec SQLite et SQLAlchemy, validation des données, documentation interactive, tests, authentification et déploiement avec Docker.
